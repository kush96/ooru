# Karnataka Sakala: service guarantees

**What:** [Official Bengaluru Urban introduction](https://bengaluruurban.nic.in/en/service/sakala-services/) to Sakala, the system for delivery of covered government services within specified time limits.

**Helps with:** "Does a government service have a formal delivery deadline?" This is an introduction and source link, not the list of all covered services.

**Do not assume:** Every civic complaint is covered, or every service has the same deadline. Before quoting a time limit or appeal route, obtain the current entry for that exact service and its designated officer (the official assigned to provide it). The linked legacy Sakala portal has not been tested end to end.

`txt_source.txt` contains the official introduction. From `ooru_be`:
```bash
uv run --group resources resources/documents/karnataka-sakala-service-guarantees/fetch.py
```
