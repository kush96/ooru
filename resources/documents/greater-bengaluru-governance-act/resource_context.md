# Greater Bengaluru Governance Act, 2024

**What:** Karnataka Act 36 of 2025: the legal framework for governing Greater Bengaluru.
`txt_source.txt` contains the full Act, not a service-responsibility summary. GBA means Greater Bengaluru Authority, the city-wide coordinating body.
**Source:** [India Code, Government of India](https://www.indiacode.nic.in/bitstream/123456789/21664/1/36_of_2025_%28e%29.pdf).
**Helps with:** Understanding the roles and powers of GBA, city corporations and ward committees.

## Useful sections to read

- **8:** Relationships between civic authorities.
- **14:** Functions of GBA.
- **103:** Functions of ward committees.
- **111:** Powers and functions of city corporations.

These are reading pointers, not an extracted responsibility map. This Act alone does not identify who maintains a particular street or provide current officers and phone numbers. Check later amendments and local notifications before using it to answer users.

## Files and refresh

- `pdf_source.pdf`: original downloaded PDF.
- `txt_source.txt`: machine-extracted text, labelled by PDF page; check the PDF if text looks wrong.
- `resource_context.md`: this handwritten note; the script never changes it.

From `ooru_be`, run (requires `uv` and `curl`):

```bash
uv run --group resources resources/documents/greater-bengaluru-governance-act/fetch.py
```

Each run downloads again and replaces the PDF and text after validation.
