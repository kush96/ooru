# Work orders and payments

**What:** Four CSVs of Bengaluru municipal work orders and payments, published as FY2025-26 data. A work order authorises a contractor to carry out work; it is not the full tender document.

**Source:** [OpenCity dataset](https://data.opencity.in/dataset/bbmp-work-orders-and-payments-2025-26). OpenCity hosts the files and lists `accounts.bbmp.gov.in` as the source. The downloaded description is in `metadata.json`.

**Helps with:** Finding recorded work descriptions, contractors and payment amounts.

**Choose carefully:** Files refer to the 198-, 225- and 243-ward boundary schemes, plus common works covering multiple wards. Ward numbers from different schemes are not interchangeable. These files do not prove that a project is completed or identify its exact street location.

**Files:** CSVs are unchanged downloads. Source URLs, download dates and file checksums are in `../../manifest.json`. There is no local fetch script for this collection yet.
